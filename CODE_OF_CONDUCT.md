# Code de conduite

Ce projet est un outil professionnel du réseau des agences d’urbanisme. Les échanges (issues, PR, e-mails) restent courtois et factuels.

## Attendu

- Critiquer le code, pas les personnes
- Pas de harcèlement, propos discriminatoires ou contenu hors sujet
- Pas de données personnelles ni secrets dans les tickets
- Les désaccords se tranchent par le mainteneur (Audiar), de façon argumentée

## Signalement

Contact : [communication@audiar.org](mailto:communication@audiar.org). En cas de manquement grave, le mainteneur peut refuser une contribution ou bloquer un compte.

Ce texte s’inspire des principes du Contributor Covenant, adapté à un projet d’agence publique.
