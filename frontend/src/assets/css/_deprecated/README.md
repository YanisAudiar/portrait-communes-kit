# Fichiers CSS dépréciés ou non utilisés

Ce dossier contient des fichiers CSS qui ne sont **jamais importés** dans l’application.

- **premium-charts.css** : styles premium pour graphiques (`.premium-chart-container`, légendes, etc.). Conservé pour référence ou fusion future dans `modern-dashboard-charts.css` si besoin.

Avant de supprimer définitivement un fichier, vérifier qu’aucun composant ne l’utilise (recherche globale sur le nom du fichier ou des classes).
